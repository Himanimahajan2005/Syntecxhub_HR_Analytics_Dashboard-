# HR Analytics Dashboard

An HR Analytics project that analyzes employee attrition, salary, experience, and department-wise trends to generate workforce insights and HR KPIs.

## Tools
- Python
- Pandas
- Power BI

## Features
- Attrition Analysis
- Department & Role Comparison
- Correlation Analysis
- HR KPI Dashboard

## KPIs
- Attrition Rate
- Retention Rate
- Employee Count
- Average Salary
